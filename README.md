# Result-Scenario Content Positioning

## English

This Codex Skill helps creators position practical or AI-assisted content around an audience's task and a visible, evidence-backed result. Products and models remain supporting tools instead of becoming the whole topic.

### Contents

- `SKILL.md` - when to use the Skill, its positioning workflow, and its boundaries.
- `test-prompts.json` - six trigger, non-trigger, and edge-case routing prompts.
- `test-results.md` - the recorded behavioral test result and the limits of this release validation.

### Boundaries

This Skill does not fact-check claims, conduct source research, or create a complete script or production plan. It requires honest evidence for any promised result and does not establish that a content format causes business outcomes.

### Sources and provenance

This is an original workflow synthesis maintained in the author's local Skill collection. It was informed by the author's analysis of publicly available creator examples. This repository intentionally excludes source videos, transcripts, private research notes, and other Skills. No third-party Skill text or assets are included.

### Validation limits

The included routing prompts are small qualitative examples, not a benchmark. The historical 6/6 routing result in `test-results.md` is reported as recorded and was not independently reproduced during this release run. Static package checks do not establish task quality or business results.
